### 简单模式匹配
定义两个指针`i` `j`分别位于主串和子串的首部,从子串的第一个字符向后匹配,如果在某一位置不匹配,`i`从当前起始位置后移一位,`j`回溯到起始位置, 直到结束/匹配成功.

当情况最坏时,假设主串长度为`n`, 模式串长度为`m`, 算法的时间复杂度为O(mn), 代码实现:
``` C
int match(char *S, char *T) {
    if (!S || !T) return -1;

    int s_len = strlen(S);
    int t_len = strlen(T);

    //空匹配
    if (t_len == 0) return 0;

    int i = 0, j = 0;
    while (S[i] && T[j]) {
        if (S[i] == T[j]) {
            i++;
            j++;
        } else {
            // 此时,子串中[0, j-1]一定是完全匹配的, 也就是说在主串[x, i-1]是完全匹配的
            // 已知共j个元素完全匹配, 可以的主串开始的位置x = i - j,后移一位便是i-j+1
            i = i - j + 1;
            j = 0;
        }
    }
    // 匹配成功标志
    return j == t_len ? i - j : -1;
}
```

### KMP算法
> 关于KMP算法的原理, 推荐知乎文章:
> 📑 https://www.zhihu.com/question/21923021/answer/281346746

KMP算法与朴素模式匹配的区别在于主串不会回退, 模式串会利用自身的结构信息避免重复的比较

#### 部分匹配表
KMP算法的核心是一个成为部分匹配表(Partical Match Table)的数组,了解PMT之前需要先明确字符串的前缀与后缀,如果存在两个字符串`A`和`B`, 满足`A = BS`, 其中`S`是任意的非空字符串, 那么称`B`为`A`的前缀字符串, 反之弱满足`A = SB`, 那么称之为`B`为`A`的后缀字符串.由于`S`有了非空的约束, 所以字符串本身既不是自身的前缀字符串, 也不是自身的后缀字符串. 然后可以引伸出前缀集合和后缀集合这个概念,给定一个字符串`abad`, 它的前缀集合为`{a, ab, aba}`, 它的后缀集合为`{d, ad, bad}`

#### PMT值的含义
PMT值的含义是字符串的前缀集合与后缀集合交集中最长元素的长度, PMT数组的长度等于待匹配模式字符串的长度,下面解释如何用PMT数组去匹配字符串:
```
                 i
       a a b a a b a a f
                 j
       a a b a a f
PMT:   0 1 0 1 2 0
next: -1 0 1 0 1 2

             3           9
       a a b a a b a a f
                         6
             a a b a a f
```     
指针`i`和`j`分别从主串和模式串的0索引开始, 第一次发生失配时`i=j=5`, 观察`[0, i-1]`和`[0, j-1]`位置,此时已经明确了主串中`[0, i-1]`这个子串, 与模式串中`[0, j-1]`的子串相同, 又知道在PMT数组`[j-1]`位的值为2, 代表这个子串的前缀集合和后缀集合交集中最大长度的元素为2, 所以在模式串中, 前两个元素不用再参与匹配, 直接从第三个元素开始匹配, 不难发现, 如果在`j`位置发生失配, 模式的指针应该回退到`PMT[j-1]`处


#### next数组
所谓`next`数组, 其核心还是`PMT`数组, 只不过将`PMT`数组每个元素的值向右移动了1位, 只使用`PMT`数组已经能够实现`KMP`算法, `next`数组的产生是为了编码的方便. 它每个元素代表的含义时, 如果模式串在`j`位置发生失配, `j`指针直接回退到`next[j]`对应的索引位置.
